# 이미지 폴더

컨텐츠지원 > IM VOCA 페이지의 앱 화면(폰 목업)에 들어가는 스크린샷입니다.

아래 이름 그대로 이 폴더에 넣으면 홈페이지에 **자동으로** 반영됩니다.
(파일이 없으면 안내용 기본 화면이 대신 보이므로, 하나만 넣어도 괜찮습니다.)

| 파일명 | 넣을 화면 |
|---|---|
| `imvoca-1.png` | 책장 (책 목록 / DAY별 단어) |
| `imvoca-2.png` | 페이지 촬영 (책 상세 · 페이지 촬영 버튼) |
| `imvoca-3.png` | 암기카드 또는 퀴즈 화면 |
| `imvoca-4.png` | 복습 현황 (에빙하우스 복습 목록) |

## 권장 사항
- 휴대폰 세로 스크린샷 그대로 (예: 1080 x 2160)
- 화면 위쪽 상태바(통신사·시간·배터리)는 잘라내면 더 깔끔합니다
- 개인정보(이름·연락처)가 보이면 가리거나 다른 화면으로 교체해 주세요
- 파일 형식은 png 또는 jpg (jpg면 확장자를 `.jpg`로 바꾸고 알려주세요)
