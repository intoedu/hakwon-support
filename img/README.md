# 이미지 폴더

## IM VOCA 앱 화면 (컨텐츠 지원 → IM VOCA)

| 파일 | 무엇 |
|---|---|
| `imvoca-1.jpg` | 책장 |
| `imvoca-2.jpg` | 뽑힌 단어 목록 |
| `imvoca-3.jpg` | 암기카드 |
| `imvoca-4.jpg` | 복습 현황 |
| `voca/ai1~4.jpg` | AI 단어추출 1~4단계 (촬영 → 단어 선택 → 단어장 완성 → 페이지별 누적) |

## 그 밖에

| 폴더 | 무엇 |
|---|---|
| `folio/` | 제작한 홈페이지 썸네일 (`FOLIO_SITES` 목록과 파일명이 짝) |
| `design/` | 브로셔·포스터 (`DESIGN_WORKS` 목록과 짝. `<이름>-1~3.jpg` 는 넘겨보기용) |
| `office/` | 인투 오피스 화면 `step1~5.jpg` |

새 그림은 **긴 변 900px · JPEG 품질 74** 정도로 줄여서 넣습니다.
`sips -Z 900 -s format jpeg -s formatOptions 74 원본.png --out 결과.jpg`
